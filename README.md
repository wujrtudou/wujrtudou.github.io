# Jinran Wu — Academic Website

A restrained, responsive academic website for GitHub Pages, including a dedicated Working Papers section.

## Deploy

1. Open the repository `wujrtudou/wujrtudou.github.io`.
2. Upload **all files and the `assets` folder** from this package to the repository root.
3. Replace existing files when prompted and commit to `main`.
4. In **Settings → Pages**, use `Deploy from a branch`, `main`, and `/(root)`.
5. Visit `https://wujrtudou.github.io/` after the Pages workflow completes.

## Structure

- `index.html` — homepage
- `research.html` — research programme
- `working-papers.html` — current manuscripts and public preprints
- `publications.html` — selected publications
- `service.html` — editorial service, teaching and awards
- `contact.html` — contact and collaboration
- `Jinran_Wu_CV.pdf` — current CV
- `assets/site.css` — visual system and responsive layout
- `assets/site.js` — mobile navigation, theme toggle and year
- `assets/favicon.svg` — site icon
- `404.html`, `robots.txt`, `sitemap.xml` — deployment and search support
